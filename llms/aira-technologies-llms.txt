# Aira Technologies

> Aira Technologies is an AI-defined networking company founded in 2019 and headquartered in
> Saratoga, California. It builds machine-learning and generative-AI software for mobile network
> operators. Its platform, Naavik (and Naavik One, "the Autonomous Network Driver for Telecom"),
> is an Adaptive Intelligence Framework for the Radio Access Network: an Intent Manager that turns
> natural language into network actions, AppGen for no-code telecom application generation, a
> reasoning agent for anomaly detection and root-cause analysis, a telecom AI/ML hub and a
> knowledge graph. Earlier work includes RANGPT, a GenAI utility for RAN observability, analysis,
> control and automation demonstrated with Broadcom and Tech Mahindra, and an AI-based channel
> estimation and prediction xApp. Member of the O-RAN Alliance, the AI-RAN Alliance and TM Forum.
> $14.5M Series B from AT&T Ventures, Intel Capital and In-Q-Tel.

**Aira Technologies publishes no API, no developer portal, no SDKs, no CLI and no API

no signup, no pricing, no key issuance and no published specification for either product. This file

The one machine-readable interface reachable on aira-technology.com is the WordPress REST content
API behind the corporate website at `https://aira-technology.com/wp-json`. It is anonymously
readable, read-only for unauthenticated callers, unversioned as a contract, and carries no
rate-limit signal, no status page, no changelog and no support channel. Consume it defensively.

## How to call it

- Anonymous HTTPS. No key, no token, no account. Collections answer `Allow: GET`.
- Pagination: `page` / `per_page` (1–100; 500 returns `400 rest_invalid_param`) / `offset`, with
  `X-WP-Total`, `X-WP-TotalPages` and an RFC 8288 `Link` header.
- Use `_fields=` to trim responses and `_embed=true` to inline author, featured media and terms in
  one request instead of N+1 fetches.
- Errors are `{code, message, data:{status}}` — match on `code`, never on `message`.
- Responses carry `Cache-Control: s-maxage=2592000`, so an edge cache may serve a record up to 30
  days stale. Check `modified` rather than trusting freshness.
- Every response carries `X-Robots-Tag: noindex`. The data is public and machine-readable, but the
  provider signals it should not be indexed as content.

## What does NOT exist

- No OpenAPI, AsyncAPI, GraphQL SDL, Protobuf or WSDL published by Aira. The OpenAPI documents in
  this repository were derived by API Evangelist from the server's own HTTP OPTIONS schemas.
- No `/.well-known/` surface at all — security.txt, openid-configuration, oauth-authorization-server,
  api-catalog, ai-plugin.json, agent-card.json and agent.json all return 404.
- No MCP server, no A2A agent card, no webhooks, no event stream. The WordPress Abilities registry
  (`/wp-json/wp-abilities/v1/abilities`) is registered on this host but returns 401 anonymously.
- No SDK on npm, PyPI, or any other registry. No CLI. No Postman collection.
- No pricing, no signup, no status page, no changelog, no deprecation policy, no SLA, no
  vulnerability-disclosure program and no trust center.
